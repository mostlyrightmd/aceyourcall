# Security

Report vulnerabilities using GitHub's private vulnerability reporting for this repository. Do not post keys, creator capabilities, application data or exploit details in public issues. If private reporting is unavailable, use the contact listed at https://mostlyright.md rather than creating a public disclosure.

Only the latest tagged release is supported initially. The hosted deployment may contain operational configuration not present in public source. Never expose the loopback operator API. Keep HTTPS, strict Origin checks, budget reservations and anonymous admission protections enabled. Self-hosters own their provider credentials, privacy notices, access controls, backups and upgrades.
